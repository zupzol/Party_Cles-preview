# Party_Cles

Party_Cles is a gravity particle toy that runs in the browser. It's one self-contained `index.html` with no dependencies and no build step.

**Play:** https://zupzol.github.io/Party_Cles/ (after GitHub Pages is turned on), or open it right now through [htmlpreview](https://htmlpreview.github.io/?https://github.com/zupzol/Party_Cles/blob/main/index.html).

- **Drag** to pull. Switch between **Pull / Push / Spin** at the top.
- **Tap** to drop a star. **Hold** to make a black hole that swallows particles.
- The **sliders** button opens the panel: stage, texture, color, physics, shapes, and astronomy (planet with moons, binary stars, pulsar, nebula), plus Reset and Randomize.
- The **share** button sends the link to friends, or copies it if your browser can't share.
- An optional ambient drone is off by default (speaker button).

`preview.png` (the link-preview image) is rendered from `index.html?preview` by the workflow in `.github/workflows/preview.yml` every time `index.html` changes.
